📘 คู่มือการนำเข้าคอร์ส

วิธีเพิ่มคอร์สใหม่ และรูปแบบไฟล์ที่รองรับ — ทุกอย่างอยู่ในไฟล์เดียว data/courses.js

1. วิธีที่เร็วที่สุด — คัดลอกตัวอย่าง

เปิด data/courses.js แล้วคัดลอก object ของคอร์สที่ต้องการ แล้ววางต่อกันใน array COURSES อย่าลืมใส่จุลภาค , หลัง object ก่อนหน้า

[
  {
    id: 'c13', slug: 'my-new-course', title: 'ชื่อคอร์สของฉัน',
    desc: 'คำอธิบายสั้น ๆ',
    category: 'เขียนโปรแกรม', level: 'ง่าย', tier: 1, credits: 1, price: 490,
    icon: '🚀', cover: 'from-emerald-100 to-green-100', rating: 5.0, students: 0,
    lessons: 3, hours: 3, certificate: true, lifetime: true,
    instructor: INSTRUCTORS.somchai,
    topics: ['หัวข้อที่ 1', 'หัวข้อที่ 2'],
    syllabus: [
      { n: 1, title: 'บทที่ 1', duration: '30 นาที' },
      { n: 2, title: 'บทที่ 2', duration: '45 นาที' },
      { n: 3, title: 'บทที่ 3', duration: '60 นาที' },
    ],
    files: [
      { name: 'slide.pdf', size: '1.2 MB', type: 'PDF' },
    ],
  },
]

บันทึกไฟล์แล้วรีเฟรชหน้าเว็บ — การ์ดใหม่จะขึ้นทันที

2. คำอธิบายทุกฟิลด์

ฟิลด์ชนิดคำอธิบายบังคับ
idstringรหัสเฉพาะ ห้ามซ้ำ ใช้เป็น id ในระบบ✅
slugstringURL สั้นของคอร์ส ใช้ตัวอักษรอังกฤษและ - เท่านั้น✅
titlestringชื่อคอร์สที่แสดงบนการ์ด✅
descstringคำอธิบาย 1-2 บรรทัด✅
categorystringหมวดหมู่ ต้องมีใน CATEGORIES✅
levelstringง่าย / ปานกลาง / ยาก✅
tier1|2|3ระดับสิทธิ์สมาชิกที่เข้าถึงได้ — Basic เข้า Tier 1, Pro ถึง 2, Premium ถึง 3✅
creditsnumberจำนวนเครดิตที่ใช้แลกคอร์สนี้✅
pricenumberราคาซื้อเดี่ยว (บาท)✅
iconemojiไอคอนแสดงบนการ์ด✅
coverclassTailwind gradient เช่น from-emerald-100 to-green-100✅
rating0–5คะแนนเฉลี่ย✅
studentsnumberจำนวนผู้เรียน (ใช้แสดงผล)✅
lessonsnumberจำนวนบทเรียนทั้งหมด — ไม่จำเป็นต้องเท่ากับ syllabus.length (syllabus คือเฉพาะบทหลัก ดูตัวอย่าง: c01 มี lessons: 18 แต่ syllabus 9 บท)✅
hoursnumberชั่วโมงเรียนรวม✅
certificatetrue/falseมีใบประกาศนียบัตร✅
lifetimetrue/falseเข้าเรียนได้ตลอดชีพ✅
instructorobjectผู้สอน: { name, title, experience, students, avatar }✅
topicsstring[]รายการสิ่งที่จะได้เรียน✅
syllabusobject[]หลักสูตร: { n, title, duration }✅
filesobject[]ไฟล์ประกอบ: { name, size, type }❌

3. รูปแบบไฟล์ที่รองรับ

ไฟล์ประกอบtypeใช้ทำอะไร
PDFPDFสไลด์ บทสรุป cheat sheet
ZIPZIPไฟล์ตัวอย่าง / starter code
XLSXXLSXเทมเพลต Excel
CSVCSVชุดข้อมูลตัวอย่าง
FIGFIGไฟล์ Figma
DOCXDOCXเอกสาร Word
SQL / YMLSQL / YMLไฟล์โค้ด / config
SQLiteDBฐานข้อมูลตัวอย่างสำหรับฝึกทำ (ใช้ใน c10)

วิดีโอ: เก็บที่ Bunny Stream / Cloudflare Stream แล้วเก็บแค่ video id — ดูรายละเอียดการตัดสินใจด้านวิดีโอที่ .kilo-workflow/02-decisions/02-final-decisions.md (ยังไม่ตัดสินใจขัดเจน)

4. เพิ่มหมวดหมู่ใหม่

แก้ array CATEGORIES ที่บนสุดไฟล์:

const CATEGORIES = ['ทั้งหมด', 'เขียนโปรแกรม', 'Web', 'AI & Data', 'ดีไซน์', 'ธุรกิจ', 'มาร์เก็ติ้ง'];

5. เพิ่มผู้สอนใหม่

const INSTRUCTORS = {
  ...
  newteacher: { name: 'อาจารย์สมชาย', title: 'Senior Engineer', experience: '8 ปี', students: 12000, avatar: '👨‍🏫' },
};

แล้วใช้ instructor: INSTRUCTORS.newteacher ในคอร์ส

6. เปลี่ยนราคาแพ็กเกจ

const PLANS = [
  { code: 'basic',   name: 'Basic',   price: 990,  quota: 3,  maxTier: 1, feats: [...] },
  { code: 'pro',     name: 'Pro',     price: 2490, quota: 10, maxTier: 2, feats: [...] },
  { code: 'premium', name: 'Premium', price: 4990, quota: -1, maxTier: 3, feats: [...] },
];

quota: -1 = ไม่จำกัด · maxTier = ระดับคอร์สสูงสุดที่เข้าถึง

7. เปลี่ยนบัญชีรับเงิน

const BANK = {
  name: 'ชื่อบริษัท',
  account: '123-4-56789-012',
  promptpay: '0123456789',
};
⚠️ ก่อนใช้งานจริง: ระบบสลิปและ QR ในเว็บนี้เป็น ต้นแบบจำลอง ไม่ได้ต่อธนาคารจริง ต้องเชื่อม SlipOK / EasySlip และเก็บสลิปใน private bucket ก่อนเปิดขายจริง ดูข้อกำหนดด้านความปลอดภัยที่ .kilo-workflow/02-decisions/02-final-decisions.md

8. ขั้นตอนนำเข้าแบบเต็ม (กำลังจะทำ)

  1. เขียนสคริปต์และอัดวิดีโอบทเรียน
  2. ตัดวิดีโอเป็น HLS แล้วอัปโหลดขึ้น Bunny Stream (เก็บแค่ video id)
  3. เพิ่มรายการคอร์สใน data/courses.js
  4. ใส่ไฟล์ประกอบลง public/files/ (โฟลเดอร์ยังไม่ได้สร้าง)
  5. ทดสอบการสั่งซื้อและการเข้าเรียน

หมายเหตุ: เวอร์ชันนี้ไม่มีฟิลด์ status คอร์สทุกตัวที่ใส่ใน data/courses.js จะแสดงบนเว็บทันทีโดยอัตโนมัติ
