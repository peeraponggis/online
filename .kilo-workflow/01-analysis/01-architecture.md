# Architecture Analysis
## Recommended Stack

### Frontend
- Next.js 15 + TypeScript
- Tailwind CSS
- App Router

### Backend
- NestJS
- PostgreSQL 16
- Redis

### Infrastructure
- Cloudflare Pages/Workers
- Cloudflare R2
- Bunny Stream

### Security
- Argon2id for password hashing
- JWT + Refresh tokens
- 2FA for admin
- Rate limiting
