# Workflow Configuration
# This file defines the 2-stage automation pipeline

## Stage 1: Local Model Preparation
- Analyze requirements
- Generate options
- Estimate costs
- Create analysis docs

## Stage 2: Kilo Auto-Development
- Review analysis
- Make decisions
- Generate code
- Log all actions

## Output Files
- 01-analysis/*.md - Analysis documents
- 02-decisions/*.md - Decision records
- 03-implementation/*.md - Implementation logs
- 04-logs/*.md - Execution logs
